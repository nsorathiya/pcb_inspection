# TASK 01 - Repository Assessment Only

## Instruction
Planning and inspection only.

Do not:
- Implement features
- Delete, move, or rename files
- Train models
- Install packages without approval

## Work
1. Read AGENTS.md and PLANS.md.
2. Inspect the complete repository.
3. Identify backend, frontend, ML code, models, image processing, datasets, runtime folders, database, tests, scripts, duplicate or risky code.
4. Run only safe discovery commands.
5. Run existing tests if already configured and no production secrets are required.
6. Create:
   - docs/repository_assessment.md
   - docs/gap_analysis.md
   - docs/proposed_phase_1_changes.md

## Acceptance criteria
- No feature implementation
- No destructive edits
- Findings are based on actual files
- Test results are honest
- Unknowns are clearly marked
- Final response recommends one small first implementation task
